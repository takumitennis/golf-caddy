## 0. 設計哲学

> **「整っているが、冷たくない。実用的だが、誇示しない。」**

Linear / Vercel の「装飾を引いた静謐さ」を骨格に、苔緑＋古紙＋朱で「日本の名門コースの応接間の落ち着き」を肉付けする。**新興 SaaS の煽り感とも、老舗ゴルフクラブの厳粛感とも違う**、中間の品格を目指す。

### 1-A. 既存アセットの扱い

| アセット | 用途 | 加工 |
|---|---|---|
| `hero-main.png` | A. Hero 背景 | 古紙オフホワイトのグラデベール（92% → 20%）を上から被せる |

| `og-image-raw.png` | OG 画像のベース | components.md §13 に従い後加工 |

### 1-B. 追加写真を入手するときの規定

visual-assets-spec.md B-3〜B-5 を継承。要点：

- **撮影時間帯**: 早朝 6-8 時 or 午後 4-6 時（ゴールデンアワー）
- **色温度**: 5000-5600K の自然光
- **彩度**: 控えめ（鮮緑禁止）
- **コントラスト**: 中程度、シャドウは潰さない
- **人物**: 日本人、控えめな表情、後ろ姿/横顔推奨、営業スマイル NG
- **構図**: 三分割、ボケは f/4-5.6 程度（極端なボケ NG）

### 1-C. NG 写真

- 紫グロー・シアン発光・ネオン光
- 過剰彩度の鮮緑芝
- 欧米のリンクスコース風（白砂バンカー目立ち）
- 富士山・鳥居・茶道などステレオタイプな「日本」
- 商標入り服装（Nike / Callaway 等）
- HDR 感が強い加工
- カメラ目線の集合写真

## 2. アイコンのトーン規定

### 2-A. 使用ライブラリは Lucide 一本

- ライセンス: ISC（商用利用可）
- 線幅: **1.5-2px** に統一
- 色: 苔緑 #2C4A3B（プライマリ）または墨 #1A1A1A
- サイズ: 18px（small） / 24px（normal） / 32px（large）
- AI 生成アイコンセットは使用禁止（テイストが揃わない）

### 2-B. 推奨アイコンマッピング

| 用途 | Lucide キー |
|---|---|
| チェック・成功 | `check-circle`, `check` |
| 電話 | `phone` |
| メール | `mail` |
| 相談・チャット | `message-square` |
| 予約・カレンダー | `calendar-check`, `calendar-days` |
| 資料・PDF | `file-text`, `download` |
| 保険・安心 | `shield-check`, `umbrella` |
| キャディ・人 | `users`, `user` |
| ロケーション | `map-pin` |
| バッジ・賞 | `award` |
| ロック・保護 | `lock` |
| 会社・建物 | `building-2` |
| CTA 矢印 | `arrow-right` |
| 開く・展開 | `plus`, `chevron-down` |

### 2-C. NG アイコン

- 3D 風、グラデーション付き、影付き
- 商標を含むもの（ブランドロゴ系）
- ゴルフボール / ゴルフクラブ / フラッグの直球モチーフ（visual-assets-spec NG リスト遵守）

## 3. イラストレーション・装飾

- **基本イラスト一切なし**。Linear / Vercel の哲学を踏襲
- セクション区切りの装飾要素も不要（背景色の切替で十分）
- 飾り罫線・斜めの帯・水彩テクスチャ等は禁止
- 唯一の例外：機会損失強調枠（C）の苔緑塗りつぶしと、Pricing Featured の朱枠 + バッジ

---

## 4. 絵文字（Emoji）の扱い

### 4-A. UI 上での使用は禁止
- 「✅」「🎉」「🚀」「💡」などの絵文字は LP 本文に登場させない
- B2B 50-60代男性ターゲットには「軽い」「子供っぽい」印象を与えるリスク
- ホストランド SaaS（Linear/Stripe/Notion）もページ本文に絵文字を使わない

### 4-B. 例外：機能アイコンの代替として
- 限定的に Lucide アイコンで代替（§2 参照）

---

## 5. 色のトーン規定（強調の使い方）

### 5-A. 朱 #B83A2E を使う場所
1. **Primary CTA ボタン**（最重要）
2. **ハイライト数字**（「600 万円」「¥2,500」）
3. **限定バッジ**（「先着 100 社・残り 89 枠」）
4. **Pricing Featured の枠線**（左列）
5. **必須フィールドの「*」マーク**

**上記以外で朱を使ってはいけない**。色の意味を希釈する。

### 5-B. 苔緑 #2C4A3B を使う場所
1. H1/H2 などの主要見出し
2. 苔緑塗りつぶしの強調枠（機会損失セクション）
3. Alert Bar / 最終 CTA セクション / Footer の背景
4. ロゴ
5. アイコンの基本色
6. Secondary ボタンの border / 文字色

### 5-C. 金茶 / 若葉 の使いどころ
- 金茶 #A88C5F: 「補助的なメダル感」が欲しいとき（M0-M3 中はほぼ使わなくて良い）
- 若葉 #7A9A6E: フォーム送信成功メッセージのバッジ等。装飾には使わない

### 5-D. NG カラー
- 純赤 #FF0000、純青 #0000FF、純黄 #FFFF00 などの原色
- 蛍光色全般
- グラデーション（背景・ボタン・文字すべて NG）
- 透明度を使った重ね（hero overlay 以外）

---

## 6. アニメーション・モーションのトーン規定

### 6-A. 許容されるトランジション
- ボタン hover の背景色変化（150ms ease-out）
- ボタン active の `translateY(1px)` 押し込み（100ms）
- リンクの underline 表示（150ms）
- FAQ アコーディオンの 「＋ → ×」回転（200ms ease-out）
- スクロール時の `scroll-behavior: smooth`

### 6-B. 禁止
- パララックススクロール
- 要素の fade-in アニメーション（AOS 系）
- ホバーで要素が拡大する（transform: scale）
- グラデーションのアニメーション
- 文字の typewriter エフェクト
- カードホバーで影が動的に変わる

### 6-C. 理由
B2B 信頼感は **「素っ気ない方が高まる」**。動かしすぎは「ベンチャー感」「個人サイト感」を強める。Linear/Stripe ともに本文セクションはほぼ動かない。

## 7. 文字組のトーン規定（補足）

brand-identity.md §4 を継承し、視覚的補強として：

### 7-A. 数字の見せ方
- 通貨記号と数字の間にスペースを入れない: `¥2,500` （`¥ 2,500` 禁止）
- カンマ区切りは半角: `2,500` （`２，５００` 禁止）
- 単位の前にスペース 1: `100 社`、`89 枠`、`30 分`
- 大きな数字を強調するときは数字だけ大きく、単位は同サイズ:  
  `<span class="stat-lg">600</span> 万円`

### 7-B. 約物の扱い
- 「！」は LP 全体で 0 個（brand-identity §4-2 原則4）
- 「？」は FAQ の Q のみ
- 全角スペースで字間を空けるのは禁止（letter-spacing で対応）
- 太字強調は `<strong>` で意味的に。装飾的な `<b>` は避ける

### 7-C. リード文の改行
- ヒーロー H1 と最終 CTA H1 のみ `<br>` で意図的な 2 行構成
- それ以外のリード・本文は `max-width` で自然改行を制御
- 重要なフレーズの前で改行したいとき: 改行ヘルパー `<wbr>` を使う

## 8. 一貫性チェックリスト（visual-implementer 用）

実装後の最終チェック：

- [ ] 色は 3 主役 + 5 中性 + 補助 5 以外を使っていない
- [ ] フォントは Inter / Noto Sans JP のみ（明朝が混入していない）
- [ ] border-radius は 4 / 6 / 8 / 999px のいずれか
- [ ] 余白は 4/8/12/16/24/32/48/64/80/96/120 のいずれか
- [ ] アイコンは全部 Lucide
- [ ] 「！」がページ全体で 0 個
- [ ] 「？」が FAQ の Q 以外で使われていない
- [ ] 絵文字（Unicode）が UI に混入していない
- [ ] グラデーションが使われていない
- [ ] アニメーションが §6 の許容範囲内
- [ ] 朱を「CTA / ハイライト数字 / 限定バッジ / Featured 枠 / 必須*」以外で使っていない
