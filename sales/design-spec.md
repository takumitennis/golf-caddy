# Caddygate 営業資料 ビジュアル Spec

作成: art-director
日付: 2026-06-04
対象: ゴルフ場オーナー・支配人（50-70代男性、保守的・信頼感重視）向け B2B 提案 PPTX
位置付け: `~/caddytas/design-system/` の token 体系を尊重しつつ、**営業資料専用**の独立 spec として記述する。既存 design-system のファイルは触らない。

---

## 0. 一行サマリー

> **「印刷された業務文書の整列と、現場写真の重み。色は引き、数字とタイポで語らせる。」**

Stripe / Linear / Vercel / Cal.com / Notion / Anthropic が 2026 で揃って到達している「committee-ready B2B」言語に合流する。すなわち**純白基調、near-black CTA、ブランド色は息継ぎだけ、ボーダー 1px、シャドウほぼなし、角丸 6-8px、タイポ重視**。さらに保守的なゴルフ場オーナー層に届かせるため、**過度なグラデ・抽象 3D・アニメーション・パーティクル・AI 量産臭のするビジュアルを全面禁止**する。

| # | 観察対象 | 抽出した型 |

| 3 | Vercel Geist Browser コンポーネント | スクショは「薄chrome のブラウザ枠 + 薄影 + 角丸 8px」で囲う。背景と chrome を同テーマで合わせる |

| 7 | Anthropic Pitch Deck（2022 leaked） | 10 スライド主義、巨大見出し + 短い説明、商品語らずに信頼を語る |
| 8 | Pocus 営業デック | Before / After は「左右 50/50 の２カラム + 上に大見出し」が王道 |
| 9 | Intercom / Zuora 営業デック | カバーは写真リッチ＋テキスト最小、本文は白基調 + 整列 |

| 14 | Big Number 系 | 単一メトリクスを巨大化、tabular-nums、出典明記 |
| 15 | 章扉 | 連番（01〜09）+ 章タイトル + 1文の３点だけ、余白 70% |
| 16 | CTA スライド | 連絡先 + QR が主役、全要素を中央寄せ、テキスト最小 |
| 17 | Browser mockup tools 比較 | Light chrome + neutral gradient bg + subtle shadow + rounded がデフォ |

| 19 | Japan 営業資料 chart | 明朝禁止、見出し Bold、本文 Regular、注釈 11-12px が標準 |

### 共通結論
1. **2026 の B2B 営業資料は「色を引く」が前提**。ブランド色は active state とリンクと CTA だけ、面積 5% 以下。
2. **CTA は near-black**。ゴルフ場オーナー層には Stripe Dashboard と同じ重さで響く。
3. **商品=スクリーンショットが主役**。ヒーロー写真はカバーと章扉だけ、本文ページは UI スクショ中心。
4. **角丸 8px、シャドウは要素を浮かせる時だけ薄く（4-6% opacity）**。
5. **章扉は大きい連番 + 章名 + 一文だけ**で「呼吸の場」を作る。

## 2. ブランドトーン継承

| 項目 | LP（古紙ベージュ系） | 営業資料（本spec） | 判断 |
|---|---|---|---|
| 基調色 | #F5F0E6 古紙ベージュ | **#FFFFFF 純白** | ゴルフ場オーナー＝紙の業務資料に慣れている世代だが、PPT/PDF として配布される営業資料は純白が標準。古紙トーンを混ぜると「LPの世界」と区別がつかなくなる |
| ブランド色 | #2f8f2f 鮮緑 | **#2C4A3B 苔緑** | dashboard で採用済みの「沈み込んだ苔緑」を流用。鮮緑だと保守層に「派手」と取られるリスク |
| アクセント | #B83A2E 朱赤 | **使わない（destructive のみ #B91C1C 文字色）** | 営業資料で赤面積を出すと「危ない」「警告」と読まれ商談が冷える |
| CTA 色 | 苔緑塗り | **#18181B near-black 塗り** | Stripe/Linear/Vercel と同じ作法。商談相手に「ちゃんとした業務 SaaS」と感じさせる |
| フォント | Inter + Noto Sans JP | **Inter + Noto Sans JP**（同じ） | 明朝禁止は厳守 |
| シャドウ | hero に薄ボカシあり | **要素には基本なし、スクショ枠だけ subtle (4%)** | ペラ感を出さない |

## 3. 固定 Spec：スライド全体ルール

### 3-1. キャンバス
- **比率**：16:9（1920 × 1080 px）。A4 横で印刷する場合は同じレイアウトのまま 297 × 210 mm に流し込む（マージン同比率で縮む）。
- **背景**：`#FFFFFF` 一択。章扉だけ `#F7F7F5`（薄ウォームグレー、surface-alt 相当）で「呼吸の場」を作る。
- **余白**：上下 64px、左右 80px（Safe Area）。コンテンツ最大幅 1760px、最大高 952px。
- **コンテンツ集中ゾーン**：水平中央 1100px 幅以内に主要要素を集約（本文スライド）。データ・対比スライドは 1760px を使って良い。

### 3-2. グリッド
- **12カラム、ガター 24px**（実寸 1760px / 12 = 約 122px、ガター込み）。
- 本文は **8カラム中央寄せ**（縦に長い読み物）。
- データは **12カラムを 3 つの 4カラムに割る**（3-up）か、**2 つの 6カラム**（before/after）。

### 3-3. タイポグラフィ（営業資料用に固定値で再定義）

PPT/Keynote に流し込むため、framework.css の clamp は使わず**固定 pt 値**で運用：

| 用途 | フォント | 太さ | サイズ (pt) | line-height | letter-spacing |
|---|---|---|---|---|---|
| Display（カバー大見出し） | Inter + Noto Sans JP | 700 | 56-64 | 1.10 | -0.02em |
| H1（章扉タイトル） | 同 | 700 | 44 | 1.15 | -0.015em |
| H2（本文スライド見出し） | 同 | 600 | 32 | 1.25 | -0.01em |
| Lead（本文導入1文） | 同 | 400 | 20 | 1.55 | 0 |
| Body（本文） | 同 | 400 | 16 | 1.65 | 0 |
| Caption（図注・出典） | 同 | 500 | 12 | 1.5 | 0.02em |
| Micro（ページ番号・ラベル） | 同 | 500 | 11 | 1.4 | 0.06em uppercase |
| Stat-LG（データ大数字） | Inter | 700 | 96-120 | 1.0 | -0.04em tabular-nums |
| Stat-MD（データ中数字） | Inter | 700 | 56 | 1.05 | -0.03em tabular-nums |
| Stat-Unit（単位） | Inter + Noto Sans JP | 500 | 24 | 1.2 | 0 |
| Chapter-Number（章扉の連番） | Inter | 700 | 180-220 | 0.9 | -0.06em tabular-nums |

**禁止**：
- 明朝・ヒラギノ明朝・游明朝の使用
- フォントの混在（Inter と Noto Sans JP のペアで全タイポを賄う）
- イタリック・装飾フォント
- 数字に Inter 以外を使うこと（必ず tabular-nums）

### 3-4. 配色トークン（営業資料専用）

| Token | Hex | 用途 | 面積目安 |
|---|---|---|---|
| `--deck-bg` | `#FFFFFF` | 本文スライド背景 | 70-80% |
| `--deck-bg-alt` | `#F7F7F5` | 章扉背景・サブカード背景 | 8-12% |
| `--deck-ink` | `#0F172A` | 見出し・大事な本文 | 12-15%（テキスト面積） |
| `--deck-ink-sub` | `#475569` | サブテキスト・キャプション | 4-6% |
| `--deck-ink-mute` | `#94A3B8` | 注釈・出典・disabled | 1-2% |
| `--deck-border` | `#E2E8F0` | カード・スクショ枠の輪郭 | 線のみ |
| `--deck-border-soft` | `#F1F5F9` | テーブル罫線・薄い区切り | 線のみ |
| `--deck-primary` | `#2C4A3B` | ロゴ・章番号・大数字・active state | 2-5% |
| `--deck-primary-deep` | `#1F3A2D` | 重要数字の強調・グラフ主線 | 1-2% |
| `--deck-primary-soft` | `#ECF3EE` | 章扉のアクセント面・確定バッジ背景 | 3-5% |
| `--deck-accent` | `#18181B` | primary button・CTA 塗り | 2-4% |
| `--deck-accent-deep` | `#0A0A0A` | hover / 強い強調 | 1% |
| `--deck-warn` | `#F59E0B` | 注意ラベルの文字（塗り禁止） | 1% 以下 |
| `--deck-error` | `#B91C1C` | destructive 文字色のみ（塗り禁止） | 1% 以下 |

**鉄則**：1 枚のスライドで使用色は最大 **3 色 + 白**まで。例外は表とグラフのみ。

### 3-5. 形・線・シャドウ

| 要素 | radius | border | shadow |
|---|---|---|---|
| カード | 8px | 1px solid `#E2E8F0` | なし |
| ボタン | 6px | none（fill） or 1px（outline） | なし |
| バッジ | 4px | none | なし |
| スクリーンショット枠 | 12px（外枠） | 1px solid `#E2E8F0` | `0 1px 2px rgba(15,23,42,0.04), 0 8px 24px rgba(15,23,42,0.06)` |
| 写真トリミング | 8px | none | なし |
| アイコン背景 | 6px（角丸正方形） | none | none |
| QR コード | 0 | 1px solid `#E2E8F0` 任意 | none |

**禁止**：
- グラデ塗り（カバー hero overlay 例外のみ）
- ネオン・グロウ
- 8px ＋ 16px 等の混在（同一スライド内で 8px か 12px のどちらかで統一）
- カードに 4px 以上の影

### 3-6. ロゴ配置（全スライド統一）

- **位置**：左上、左端から 80px、上から 56px。
- **サイズ**：ワードマーク高さ **28px**（幅は比率で自動、約 113px）。
- **使用バリエーション**：`~/caddytas/assets/logo-wordmark.png` を白背景に黒/苔緑で配置。背景が #F7F7F5 / 苔緑塗りの場合は白抜き版を別途用意。
- **カバースライドのみ例外**：ロゴはスライド中央上部、ワードマーク高さ 56px。
- **シンボル単独使用**：CTA スライドの QR の左横、シンボル高さ 40px。

### 3-7. ページ番号・フッター

- **位置**：右下、右端から 80px、下から 40px。
- **書式**：`03 / 14`（現在 / 全数、Inter 700 11pt + Inter 500 11pt、色 `#94A3B8`、tabular-nums）。
- **カバーには表示しない**。章扉には表示する。

### 3-8. アニメーション

- 本資料は **配布前提（PDF / PPT）**。アニメーションは**フェードのみ最大 200ms**、それ以外（スライドイン、ズーム、回転、自動再生）すべて禁止。
- 章扉から章本文へ：fade 150ms のみ。

## 4. 固定 Spec：8 種類のスライドフォーマット

PPTX マスタースライドとして 8 種類を作成し、後続のスライドはこれを複製して中身を差し替える運用。

### Type A：カバースライド

```
+----------------------------------------------------+
|                                                    |
|              [Caddygate logo wordmark]             |  ← 中央上、56px 高
|                                                    |
|                                                    |
|     キャディ不足を、                                |  ← Display 64pt 苔緑/黒
|     需要連動マッチングで解く。                       |
|                                                    |
|     Caddygate がゴルフ場運営に                      |  ← Lead 20pt ink-sub
|     もたらす、新しい労働力供給の標準                  |
|                                                    |
|                                                    |
|     [社名・提案先名 + 日付]                          |  ← Caption 12pt mute
|                                                    |
+----------------------------------------------------+
   背景：純白 #FFFFFF
   または：背景に淡くゴルフ場写真（透過 8%、上半分のみ）
   ページ番号：なし
```

**ポイント**：
- Stripe Atlas 流儀で社名・タグライン・短いサブのみ。アイコンや派手な装飾は置かない。
- 背景写真を使う場合は **opacity 8%以下** で「気配」だけにする。商品写真の主張は出さない。
- 提案先名（例：「〇〇カントリークラブ様」）と日付は左下に caption 12pt で控えめに置く。

### Type B：章扉スライド

```
+----------------------------------------------------+
|  [logo]                                            |
|                                                    |
|                                                    |
|     01                                             |  ← Chapter-Number 200pt 苔緑
|                                                    |
|     なぜ今、キャディ問題か                            |  ← H1 44pt 黒
|                                                    |
|     全国で 1.8 万人のキャディ職が不足し、              |  ← Lead 20pt ink-sub
|     現役の平均年齢は 58 歳。                          |
|                                                    |
|                                                    |
|                                            03/14   |
+----------------------------------------------------+
   背景：#F7F7F5 薄ウォームグレー
```

**ポイント**：
- 連番は **苔緑 #2C4A3B、200pt**。これだけで章扉の機能を果たす。
- 章タイトルは 44pt、1 行に収める。
- 1 文の説明は 2 行まで。要素は連番＋タイトル＋1 文の **3 つだけ**。
- 左 80px のグリッドに左揃え、上から 30% の高さに連番、その下に 24px gap でタイトル。

### Type C：本文スライド（見出し + 本文 + サブビジュアル）

```
+----------------------------------------------------+
|  [logo]                                            |
|                                                    |
|  キャディ不足の構造的要因                             |  ← H2 32pt 黒
|                                                    |
|  ┌─────────────────────┐  ┌─────────────────┐    |
|  │  本文テキスト         │  │                 │    |
|  │  Lead 20pt 1 文導入  │  │  サブビジュアル  │    |
|  │  Body 16pt 3-4 段落  │  │  写真 or 図解    │    |
|  │  bullet ▸ ...        │  │  比率 4:3        │    |
|  │  bullet ▸ ...        │  │                 │    |
|  │                     │  │                 │    |
|  └─────────────────────┘  └─────────────────┘    |
|     7 cols                       5 cols            |
|                                                    |
|  出典：日本ゴルフ場経営者協会 2025 報告      04/14    |
+----------------------------------------------------+
```

**ポイント**：
- 12 カラムを **7:5** で割る。文章左、ビジュアル右が原則。逆も可（章ごとに左右リズム）。
- 本文は **Lead 1 文 + Body 段落 2-3 + bullet 3-4 個**まで。25-40 words/slide。
- bullet マーカーは `▸` （U+25B8）苔緑 #2C4A3B 12pt、テキストは黒 16pt。
- サブビジュアル：写真または図解。サイズは 580 × 435 px。border 1px #E2E8F0、radius 8px、shadow なし。
- 出典は左下、12pt、`#94A3B8`。

### Type D：データスライド（大数字 + 注釈）

```
+----------------------------------------------------+
|  [logo]   業界の現状                                |  ← Micro 11pt ラベル
|                                                    |
|                                                    |
|                                                    |
|         1.8                 58 歳                  |  ← Stat-LG 120pt
|         万人                平均年齢                |  ← Stat-Unit 24pt
|                                                    |
|         全国のキャディ      現役キャディの          |  ← Body 16pt サブ
|         不足見込み (2025)   高齢化が進行              |
|                                                    |
|                                                    |
|  出典：日本ゴルフ場経営者協会 2025 / e-Stat      05/14|
+----------------------------------------------------+
```

**ポイント**：
- **1 メトリクス**を巨大化が王道。複数置く場合も **最大 3 つまで**。
- 数字は Inter 700 120pt、tabular-nums、苔緑 `#2C4A3B`。
- 単位「万人」「歳」「%」は別行で 24pt、`#475569`。
- 下に Body 16pt で 1 行説明、その下に Caption 12pt で出典。
- 数字以外の装飾（グラフ、アイコン、矢印）は**置かない**。

### Type E：対比スライド（Before / After）

```
+----------------------------------------------------+
|  [logo]                                            |
|                                                    |
|  従来の人材確保 vs Caddygate                        |  ← H2 32pt 黒
|                                                    |
|  ┌─────────────────────┐  ┌─────────────────────┐ |
|  │ BEFORE              │  │ AFTER               │ |  ← Micro 11pt uppercase
|  │ 従来                 │  │ Caddygate 導入後     │ |
|  │                     │  │                     │ |
|  │ × ハローワーク常設    │  │ ✓ 需要連動マッチング  │ |  ← Body 16pt
|  │ × 派遣会社月額固定   │  │ ✓ 出走時のみ稼働費用  │ |
|  │ × 高齢化で 5 年限界  │  │ ✓ 平均年齢 38 歳     │ |
|  │                     │  │                     │ |
|  │ 月額 ¥420,000        │  │ 月額 ¥168,000        │ |  ← Stat-MD 56pt
|  │                     │  │                     │ |
|  └─────────────────────┘  └─────────────────────┘ |
|     6 cols                    6 cols               |
|     bg: #F7F7F5             bg: #ECF3EE            |
|                                                    |
|  注：30 ラウンド/月想定の試算           06/14         |
+----------------------------------------------------+
```

**ポイント**：
- **6:6 二等分**、ガター 32px。
- Before は背景 `#F7F7F5`、After は背景 `#ECF3EE`（苔緑 soft）。色面積で意味を持たせる。
- 上に「BEFORE / AFTER」のラベル、その下にチェック/バツ箇条書き、下に金額（Stat-MD）。
- バツは `×` 1 文字を `#94A3B8`、チェックは `✓` 1 文字を `#2C4A3B`。アイコンは使わない。
- After 側の金額は `#1F3A2D`、Before は `#0F172A`。

### Type F：スクリーンショットスライド（プロダクト UI）

```
+----------------------------------------------------+
|  [logo]                                            |
|                                                    |
|  支配人ダッシュボード                                |  ← H2 32pt
|  出走予定とキャディ稼働を 1 画面で                    |  ← Lead 20pt sub
|                                                    |
|  ┌──────────────────────────────────────────────┐ |
|  │ ╔════════════════════════════════════════╗   │ |  ← browser chrome
|  │ ║  ● ● ●   caddygate.app/dashboard       ║   │ |
|  │ ╠════════════════════════════════════════╣   │ |
|  │ ║                                        ║   │ |  ← actual screenshot
|  │ ║      [ダッシュボード UI 実画面]          ║   │ |
|  │ ║                                        ║   │ |
|  │ ╚════════════════════════════════════════╝   │ |
|  └──────────────────────────────────────────────┘ |
|                                                    |
|  ① 出走予定一覧  ② 稼働キャディマップ  ③ 当日連絡   |  ← Body 16pt 注釈
|                                                    |
|                                            08/14   |
+----------------------------------------------------+
```

**ブラウザ枠 spec（Vercel Geist Browser を参考）**：
- 枠幅：1440 × 900 px（実スクショ）にラップ。
- chrome 高さ：40px、背景 `#FAFAFA`、左に dots 3 個（直径 12px、薄グレー）、中央に URL bar（`#FFFFFF`、border 1px `#E2E8F0`、radius 6px、文字色 `#475569` 13pt）。
- 外枠：radius 12px、border 1px `#E2E8F0`。
- 影：`0 1px 2px rgba(15,23,42,0.04), 0 8px 24px rgba(15,23,42,0.06)` — 弱め、浮かせすぎない。
- スクショ内の UI は **dashboard-framework.css の色体系**で統一（白基調 + 苔緑 active）。

**モバイル枠 spec**：
- iPhone 風モック使用、ベゼル `#0F172A`、radius 32px、Dynamic Island あり。
- 幅 360px、高さ 720px。
- 影：同上、弱め。
- iPhone 15 Pro テンプレ寄り。

**配置とキャプション**：
- スクショは 1 枚なら中央寄せ、最大幅 1280 px。
- 2 枚（PC + モバイル）並べる場合は 8:4 で割り、PC 左、モバイル右。
- キャプションはスクショの下に Body 16pt、最大 2 行。番号付きでスクショ内の特徴箇所を指す場合は `①②③` を Inter 14pt で。

## 5. アイコン・図解の作法

### 5-1. アイコン
- **Lucide Icons**（線アイコン）を全面採用。線幅 1.5px、サイズ 20-24px、色は `#0F172A` または `#2C4A3B`。
- 装飾用の塗りアイコン・カラフルアイコン・絵文字は**全面禁止**。

### 5-2. 図解
- フローチャート的な図解が必要な場合は、**矩形ボックス（radius 8px、border 1px、背景 #FFFFFF）+ 矢印（→ 文字または 1px line + 三角）+ Body 16pt テキスト**で構成。
- 図解の色数：**黒 + 苔緑 + 薄ウォームグレー の 3 色のみ**。
- 円グラフ・ドーナツ：使用可。塗りは `#2C4A3B`（主） / `#94A3B8`（副）の 2 値のみ。
- 棒グラフ：縦棒のみ、塗りは `#2C4A3B` 単色、ラベルは Caption 12pt。

### 5-3. 写真の使い方
- 本文スライドの写真は **ゴルフ場の現場感** に振る：
  - ✓ フェアウェイの早朝霧・斜光
  - ✓ クラブハウスのエントランス（無人）
  - ✓ キャディバッグ・カート・芝などの「道具クローズアップ」
  - ✓ キャディの後ろ姿（顔判別不可、制服のリアリティを示す）
- 避ける：
  - ✗ ゴルフ場の派手な俯瞰ドローン（商業臭）
  - ✗ ニッコリ笑う外国人モデル（ストック感）
  - ✗ AI 生成の超リアル人物（オーナー層は見分ける）
  - ✗ プロゴルファーがスイングしている瞬間（華やかすぎ）
- 写真はすべて **横長 4:3 または 16:9**、radius 8px、border なし、shadow なし。

## 7. PPTX 制作時の運用ルール

### 7-1. マスタースライド
- Type A〜H をそれぞれ PPTX マスターとして登録。Type C / D / F は左右リズム用に Variant 2 種ずつ作っておく。
- マスター上に置くもの：ロゴ、ページ番号フィールド、Safe Area ガイド（非表示）。

### 7-2. フォント埋め込み
- Inter は Web フォントなので PPTX に「フォント埋め込み」を必須。Noto Sans JP も同様。
- 埋め込みできない環境向けに「Inter → メイリオ / Yu Gothic UI」のフォールバックを設定。明朝へのフォールバックは絶対禁止。

### 7-3. PDF 出力
- 印刷配布も想定し、PDF/X-4 で出力。RGB のまま OK（モニタ視聴前提）。
- 1 ページ = 1 スライド、ノートはエクスポートしない。

### 7-4. 改変ルール
- 営業先ごとに変えるのは **カバーの提案先名 / 日付 / 連絡先** のみ。本文の構成・色・タイポは固定。
- 提案先ごとの数字差し替え（「貴クラブの場合」シミュレーション）は Type D に1枚追加する形で挿入する。
